01Quick start

Agents Atelier builds front ends only: static websites in plain HTML, CSS and JavaScript. It runs on your machine and uses your own Claude Code login, so there's no API key to set up.

STEP 1

Pick your team

The shared agents are ready to use. Duplicate any of them on the Agents page to make your own version, or save a team for a kind of job.

STEP 2

Create a project

Click New project, give it a name and a description, then describe the page you want. To improve a site you already have, use Existing site and pick its folder or a .zip (HTML, CSS, JS, Markdown and assets only).

STEP 3

Watch & refine

Agents build it one after another. Ask for changes anytime, then download the .zip.

02The studio

Each project opens in the studio: the chat on the left, the live page on the right, and the team at the bottom.

Chat

  • Every agent posts a card with each file it reads or edits, a timer and a short summary.
  • While agents work, the send button turns into a stop button. After a stop you can Continue or Start again.
  • Follow-up prompts build on the files that are already there.

Preview

  • Reloads after every edit and keeps your scroll position.
  • Switch between desktop, tablet (768px) and phone (375px).
  • The Code tab shows every file, with a dot on the ones that changed.

Team panel

  • One tile per agent: ready, waiting, working (with a live timer and current action), done or off.
  • Use the switch on a tile to turn that agent on or off for this project.
  • Click a tile that already worked to jump to its card in the chat.

Versions

  • A version is saved before every run and after each agent, or whenever you click Save version now.
  • Open, compare with the current code, download, or restore any version. Restoring saves the current code first.

Cost & time

  • See estimated cost, time and tokens per agent, for this project or all projects.
  • Each agent card shows how long it took and what it cost.

Editing & retries

  • The Code tab is an editor. Turn Auto-save on, or save with the button or Ctrl+S.
  • The retry button on an agent's card runs just that agent again, with an optional extra instruction.
  • Attach, paste or drop reference images on the prompt; agents look at them before they work.

Header

  • Click the title to rename the project, or the #id to copy it.
  • The folder button opens every project, with search.
  • .zip downloads the code. It's locked while agents are working.

03Writing prompts

Agents only know what you tell them and what's already in the files. Specific prompts get specific pages.

Vague“a website for my business”
Better“a one-page site for Lumen, a bike repair shop in Lyon: hero with booking button, services with prices, opening hours, map link”
Vague“make it look nicer”
Better“use a calm, editorial look: off-white background, one serif for headings, more white space between sections”
Too much at once“redo everything and add a blog, a shop and dark mode”
BetterAsk one change per prompt, and switch off agents you don't need for it, so each run is faster.

04The agent team

Agents run in order, and each one does a single job. Faded agents are off by default; switch them on per project in the Team panel.

05Custom agents

Shared agents are the same for everyone, and only an admin can change them. Duplicate one on the Agents page to make your own version, or create a new one. Only you see your agents, and changes apply to the next run. The format below is what export and import use.

# agents/16-dark-mode.md   ← the number sets the run order
---
id: dark-mode
name: Dark mode
icon: eye             # any icon from the Agents page picker
model: sonnet         # optional: which Claude model runs it
color: "#334455"
default: false        # off for new projects
---
You are the Dark mode agent. Add a dark theme using
prefers-color-scheme, reusing the CSS variables in :root.

agents/_common.md holds the shared rules every agent receives before its own role, such as which files make up a project and “plain HTML/CSS/JS only”.

06Projects & files

Each project has its own name, description, UUID, URL, folder and saved chat. The name and description are required, and the agents read them with every prompt, so describe what the page is for and who it's for.

WhereWhat

work/.projects/Project name, chosen agents and the saved chat log

08FAQ

How long does a run take?
Each agent takes about 20–60 seconds, so the default team of 10 needs roughly 5–8 minutes. Switch off agents you don't need, or start the server with AGENT_MODEL=sonnet ./run.sh for faster runs.
Does it cost anything?
Agents use your Claude Code plan, and each agent counts as one Claude Code session. A run with 10 agents is about 10 sessions.
Can agents touch other files on my computer?
Each agent runs inside its project folder with file tools only (read, write, edit, search). Shell commands, web access and sub-agents are blocked.
What happens when I stop the agents?
Nothing is lost. Agents that finished keep their work, and the run is saved. The chat and the Team panel then offer Continue, which picks up at the agent that was stopped and skips the ones already done, or Start again, which runs the whole team again on the same request. The same choice appears if an agent fails or the server restarts mid-run.
Can the team build a site with several pages?
Yes. List the pages when you create the project (or later, in its details), one per line, for example Home, About, Contact. The agents build every page with the same header, navigation and footer, and the switcher above the preview shows each one.
Can the team build a back end, a database or logins?
No. Agents Atelier is for front ends only: the agents write static HTML, CSS and JavaScript that runs in the browser. Forms and login screens look and behave right on the page, but nothing is sent or stored; connect them to your own back end afterwards.
Why is the download button locked?
While agents are working, files change every few seconds, so a download could catch a half-finished page. The button unlocks as soon as the run finishes or you stop it.
Who can see my projects, agents and teams?
Your projects and the agents and teams you make are private to you, though admins can open every project. A site's preview link works for anyone you send it to.
Why can't I edit a shared agent?
Shared agents and teams are the same for everyone, so only an admin can change them. Duplicate one to get your own copy, then change anything you like.
Can I edit the generated code myself?
Yes. The files live in work/<uuid>/. Edit them in any editor; the next prompt's agents read the current files first.
