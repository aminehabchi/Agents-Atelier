Follow-ups only use the agents they need

After the first build, an Orchestrator reads each new request and picks the agents for it. A wording fix goes to the Copywriter. New colours go to the design agents.

The Critic can send work back

The Critic scores fit, polish, copy, responsiveness, accessibility and code. Bigger problems return to the agent responsible, and the Critic checks the page again.

It asks before it guesses

When a request is vague, or a template still has blanks like [your business], the Orchestrator asks a few quick questions with ready-made answers. Click one, type your own, or skip.

Big changes wait for your yes

A full redesign or removing pages shows the plan first: what changes and which agents work. Nothing runs until you press Yes, start.

Safety and limits

What the agents can do, and what they can't.

Kept inside the project

  • Agents only read, write and search files inside their project folder.
  • They can't run shell commands. Only agents you give web research can use the web.
  • Text inside project files is treated as data, so it can't give the agents new orders.
  • You get a warning if a page ends up with something the rules forbid.

Front end only

  • The team builds what runs in the browser. It doesn't build servers or databases.
  • Forms and login screens look and behave right, but nothing is sent or stored until you connect your own back end.
  • AI can make mistakes, so read the text and test the page before you publish it.

Questions

What people ask before they start.

How long does a build take?

A first full build usually takes 5 to 10 minutes. Follow-up changes are faster because only the agents they need will run, and you can switch off any agent you don't need.

Do I need to know how to code?

No. You describe what you want in plain words and answer a few optional questions. If you do code, you can edit every file yourself.

What is it built on?

Each agent is a Claude Code session with its own role. Every run shows how long each agent took and its estimated cost.

What happens if I stop a build?

Nothing is lost. Finished work is kept, and you can continue from the agent that stopped or start again. The same choice appears after an error or a server restart.

Can I undo a change?

Yes. A version is saved before each run and after each agent. You can compare any version with the current code and restore it in one click.

Can I change how the agents work?

Yes. Duplicate a shared agent and edit its instructions, or write a new one in plain Markdown. Your agents and teams are private to you.

Why do I need my own Claude API key?

Your agents run on your own Claude account, so you pay Anthropic directly, at their prices, with no markup. Create a key at console.anthropic.com and paste it in your profile. It's checked once, kept encrypted, and only its last four characters are ever shown.

What does hiring an agent cost?

There's no fee per hire. Agents run on your own Claude API key, so a job costs what Claude charges for it. Each agent's profile shows its average time and cost per job, and a team's page estimates the whole team before you start.

Which languages can I use?

The app speaks English, French and Moroccan Darija. Your site can be in any language, or in several: the Translator agent adds a language switcher and right-to-left layouts.

Can my site receive messages from visitors?

The sites are front end only, so they don't store messages. Contact forms send them where you already read them: WhatsApp, Telegram or the visitor's email app opens with the message written, and they press send.

Who can see my projects?

Your projects are private to your account, though admins can open every project. On the Agency plan you can invite editors, who can work on a project, and viewers, who can only watch.

How do I show a site to a client?

Create a share link in the studio's Share tab. Your client opens a read-only copy of the site without an account, until the date you choose. They can pin comments on the page, and you see them live, ready to turn into a request for the team.
