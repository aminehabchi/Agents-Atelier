How it works

One prompt in. A finished page out — and you see every step.

Each agent is your local Claude Code with a single job. They share one folder of files and pass the work down the line. Front end only: the result is a static site that runs in the browser, with no server code or database.

Features

You direct the team. Nothing is ever lost.

Every step is visible, saved and reversible — and you can step in at any point.

Stop, continue or start again

Stop the run whenever you like. Every finished agent's work is kept, so you can continue from where it stopped — even after an error or a server restart.

Saved after every agent

Retry one agent

Not happy with the colours? Ask only the CSS agent to try again, with an extra instruction like “warmer palette, bigger headings”.

One agent, not the whole team

Versions of every step

The code is saved before each run and after each agent. Open any version, compare it line by line, download it, or restore it in one click.

Up to 150 versions per project

Edit the code yourself

Small fix? Change it directly in the Code tab, with auto-save on or off. The preview updates as soon as you save.

Ctrl+S to save
