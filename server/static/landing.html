The specialists

This is the default team for a new website. Twenty-six more join when the job needs them, such as Research, Typography, Translator, Forms, WhatsApp, Legal pages and 3D.

Agents that don't wait on each other, like Design System and Copywriter, work side by side, so the build finishes sooner.

  4. 04HTMLBuilds every page with semantic, accessible markup.
  5. 05CSSStyles every element, starting from the phone layout.
  6. 06JSAdds the menu, tabs, forms and other interactions.
  7. 07ResponsiveMakes the layout work from 320px phones to wide screens.
  8. 08AnimationAdds restrained motion and respects reduced-motion settings.
  9. 09AccessibilityChecks against WCAG 2.2 AA and fixes contrast, focus and labels.
  10. 10CriticScores the result, fixes small issues and sends bigger ones back.

Each change runs only the agents it needs

After the first build, the Orchestrator reads each request and picks its agents. A wording fix goes to the Copywriter, new colours to the design agents.

The Critic can send work back

The Critic scores fit, polish, copy, responsiveness, accessibility and code. Bigger problems return to the agent responsible, and the Critic checks the page again.

It asks before it guesses

When a request is vague or a prompt still has blanks like [your business], the Orchestrator asks a few questions with suggested answers. Pick one, type your own, or skip.

Big changes wait for your yes

A full redesign or removing pages shows the plan first: what changes and which agents work. Nothing runs until you press Yes, start.

Safety and limits

What the agents can do, and what they can't.

Kept inside the project

  • Agents only read, write and search files inside their project folder.
  • They can't run shell commands. Only agents you give web research can use the web.
  • Text inside project files is treated as data, so it can't give the agents new orders.
  • You get a warning if a page ends up with something the rules forbid.

Front end only

  • The team builds what runs in the browser. It doesn't build servers or databases.
  • Forms and login screens look and behave right, but nothing is sent or stored until you connect your own back end.
  • AI can make mistakes, so read the text and test the page before you publish it.

Questions

What people ask before they start.

What do I need to start?

An account and a Claude API key from console.anthropic.com. The Starter plan is free, and a full site usually costs about $1.50–2 in Claude usage.

How long does a build take?

A first full build usually takes 5 to 10 minutes. Follow-up changes are faster, because only the agents they need will run.

Do I need to know how to code?

No. You describe what you want in plain words and answer a few optional questions. If you do code, you can edit every file yourself.

What is it built on?

Each agent is a Claude Code session with its own role. Every run shows how long each agent took and its estimated cost.

Can I change how the agents work?

Yes, on the Pro plan. Duplicate a shared agent and edit its instructions, or write a new one in plain Markdown. Paid agents you buy work as they are, because their instructions stay their creator's.

Can I earn money with my agents?

Yes, on the Agency plan. Publish an agent or a team at $1 to $100; once an admin approves it, members buy it with PayPal and you earn 70% of each sale. Your Earnings page shows sales and profit, and pays out to your PayPal from $10.

Why do I need my own Claude API key?

Your agents run on your own Claude account, so you pay Anthropic directly, with no markup. Create a key at console.anthropic.com and paste it in your profile, where it's kept encrypted and only its last four characters are shown.

What does hiring an agent cost?

Official agents have no fee: a job costs what Claude charges on your own key. Some community agents and teams have a one-time price, paid once with PayPal. Every profile shows the average time and cost per job.

Can I change or cancel my plan?

Yes, from your profile at any time. A paid plan starts as soon as PayPal confirms the payment. Moving down applies at once: you keep your projects, but can't start new ones beyond the plan's limit.

Which languages can I use?

The app speaks English and French. Your site can be in any language, or in several: the Translator agent adds a language switcher and right-to-left layouts.

Do I own the website the agents build?

Yes. You download plain HTML, CSS and JavaScript files and host them wherever you like, and nothing ties them to Agents Atelier. On Starter, the download includes a small “Made with Agents Atelier” line; Pro and Agency downloads don't.

Can my site receive messages from visitors?

The sites are front end only, so they don't store messages. Instead, contact forms open WhatsApp, Telegram or the visitor's email app with the message already written.

Who can see my projects?

Your projects are private to your account, though admins can open every project. On the Agency plan you can invite editors, who can work on a project, and viewers, who can only watch.

How do I show a site to a client?

Create a share link in the studio's Share tab: your client opens a read-only copy without an account, until the date you choose. They pin comments on the page, and you turn each one into a request for the team.

What job will you give the team first?

Create an account, describe the job in a few lines, and watch ten specialists start work.
