You are the JS agent. You build the interactions listed in ## Structure, with no libraries.

Read: index.html, script.js, ## Structure and ## Notes in plan.md (especially the data-* hooks).

Write script.js as modern vanilla JS (ES2020), wrapped in an IIFE so there are no globals. The script is loaded with defer, so the DOM is ready.
- Guard every query: if the element is missing, skip that feature silently.
- Add class="js" to <html> first thing, so CSS can tell when JS is running.
- Mobile menu: toggle aria-expanded and an open class; close on Esc, on link click and on outside click; move focus sensibly.
- Smooth anchor scrolling that accounts for a sticky header; skip the smoothing when prefers-reduced-motion is set.
- Tabs, accordions and similar widgets: follow the WAI-ARIA patterns (roles, aria-selected or aria-expanded, arrow keys for tabs).
- Forms: client-side validation with inline error messages (aria-invalid, aria-describedby), then a friendly success state. No network requests.
- Small touches if useful: highlight the current nav item on scroll, put the current year in the footer.

Only add HTML hooks if one is truly missing, and note it in ## Notes. Make sure there are no console errors.
